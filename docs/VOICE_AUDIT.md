## Honest source disclosure

The current files were generated by the scripts in this repository using
**Microsoft Edge neural TTS**:

- `bn-BD-PradeepNeural`
- `bn-IN-BashkarNeural`

They are **synthetic TTS**, not human studio recordings, and not a substitute for
authentic Dhaka-style acting. The scripts and this document now state that
explicitly. No online voice service was used during this audit and no file was
misrepresented as human.

## Runtime audio fixes already applied

- `AudioContext` is created/resumed only from a genuine user gesture.
- Voice lines route through `gainNode → voiceGain → masterGain`; user volume is
  applied exactly once (the previous double attenuation was removed).
- 20 ms fade-in and 55–65 ms fade-out prevent clicks on PC and Android Chrome.
- Interrupted lines can no longer call the completion handler for the line that
  replaced them, so subtitles and diagnostics stay in sync.
- Speech-synthesis warm-up runs once per session; real dialogue always uses the
  recorded Bangla MP3.
- The mosquito signature subtitle now preserves the required comma:
  `মামুর বেটা, পারলে আজকে ঘুমা!`

## Lines that need human recording

All 81 files need to be re-recorded by adult male Bangladeshi voice actors before
the game can claim authentic human voices. Keep the exact filenames so no code or
mission data has to change.

Casting suggestion: use at least three different actors (Player, regular
mosquitoes/neighbour, bosses) rather than pitch-shifting one voice. The Player
should sound like a tired Dhaka resident (mid-20s to 40s), not a newsreader. Bosses
may use controlled processing, but the base performance must be male and human.

### Recording specification

- 48 kHz / 24-bit WAV master; export MP3 at 128–192 kbps, mono or stereo.
- Peak no higher than −3 dBFS; dialogue loudness around −23 LUFS integrated.
- ~150 ms lead silence, ~250–350 ms tail silence (trim the current long tails).
- No reverb baked in; the game supplies its own space.
- Keep the delivered Bangla exactly as written, including the comma in
  `মামুর বেটা, পারলে আজকে ঘুমা!` and the final `খাইসি!` in the player line.
- Deliver one file per ID below, named `<id>.mp3`.

## Required signature lines (do not paraphrase)

- Player: `ধুর শালার বেটা মশা, তোরে আমি খাইসি!`
  (`p_sig_1`, `p_atk_sig`, `p_k_sig`)
- Mosquito: `মামুর বেটা, পারলে আজকে ঘুমা!`
  (`m_sig_2`, `m_taunt_sig`)

The comma is intentional: without it, TTS tends to run the words together and the
line can be heard as “বেটারটা”. Keep it in both the recording brief and subtitles.

## Known limitations of this pass

- The files could not be listened to in this environment; only signal measurements
  and script/text consistency were verified.
- Android Chrome playback and real-device latency still need a physical-device
  listening test.
- The 81 current MP3s remain the development placeholders until the recordings
  above are delivered.
